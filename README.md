# 字幕透镜 (Subtitle Lens)

Chrome 扩展（Manifest V3）：在 YouTube / Bilibili 播放器上注入一个可拖动、可缩放的"毛玻璃透镜"，遮挡烧录在画面里的中文字幕，英文与画面其余部分不受影响。

## 安装（开发者模式加载）

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（`subtitle-lens/`）

## 使用

- 打开 YouTube / B站 视频页，播放器下部（约 84% 高度处）自动出现透镜
- **拖动**透镜移位置；**右下角**悬停出现小方块，拖它改大小
- 点击扩展图标打开 popup：
  - 显示/隐藏透镜（隐藏 = 露出中文对答案）
  - 强度滑杆 0–30（默认 16）
  - 高级区：模糊档（默认）/ 形态学擦除档（仅 Chrome/Edge 支持，其他浏览器自动禁用并回退）
- 只记住「模式 + 强度」；**透镜位置每次刷新回到默认位**（有意为之）

## 已知限制

- 画中画（PiP）小窗是独立系统窗口，透镜不跟随
- 中英混排同一行的字幕只能整行盖住（空间上无分隔）
- 描边很粗或彩色综艺花字可能擦不干净（形态学档预期行为）
- B站/YouTube 改版可能使挂载选择器失效，优先更新 `content.js` 顶部 `CONTAINER_SELECTORS`

## 权限

仅 `storage`（保存模式与强度）。无网络权限，纯本地运行。
